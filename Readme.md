# Agentic-Reasoning Course

This repository contains tasks and projects developed as part of the **Agentic-Reasoning Course**. Each task is organized in its own folder, with clear documentation and instructions to ensure reproducibility and ease of understanding.

The goal of this course is to design, implement, and evaluate **agentic systems** that can reason, plan, and execute complex workflows autonomously.

---

## Repository Structure

Each task lives in a separate directory and follows a consistent structure:

```text
Agentic-Reasoning/
├── Task-1/
│   ├── README.md
│   ├── src/
│   ├── examples/
│   └── requirements.txt
├── Task-2/
│   ├── README.md
│   └── ...
└── README.md
```

* **Task-X/**: Folder for an individual task
* **README.md**: Task-specific documentation
* **src/**: Source code for the task
* **examples/**: Sample inputs/outputs or demos
* **requirements.txt**: Dependencies (if applicable)

## Tasks

### Task 1: LaTeX to Presentation Agent

**Objective:**
Create an agent that can automatically generate **PowerPoint (PPTX)** or **Beamer** presentations using the **TeX source of a research paper**.

**Key Features:**

* Parses LaTeX research papers
* Identifies structure such as title, abstract, sections, figures, and tables
* Converts content into presentation-friendly slides
* Supports:

  * PowerPoint (`.pptx`)
  * Beamer (`.tex`) presentations
* Modular and extensible agent design

Refer to `Task-1/README.md` for detailed instructions, usage, and examples.
